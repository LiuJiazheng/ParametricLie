# v0.2.2 — Specialization + generic field-of-fractions analysis

## Goal

Support **exact specialization** to defined fibers, and compute **generic invariants**
over the fraction field \(K = \mathrm{Frac}(k[a_1,\ldots,a_m])\).

## Deliverable (boundary)

> Support exact specialization to defined fibers and compute generic invariants
> over the fraction field. Generic results certify values on some nonempty
> Zariski-open subset, but **v0.2.2 does not yet identify or certify the
> exceptional locus.**

| Milestone | Question answered |
|-----------|-------------------|
| v0.2.1 | Does this parametric bracket **identically** satisfy Jacobi? |
| v0.2.2 | What does the **generic** fiber look like, and what do **concrete fibers** at specified parameter values look like? |
| later | **Which** parameter values are exceptional? |

## Family → two views

```
family L_a
 ├── generic analysis over QQ(a)     # analyze_generic / analyze on Frac
 └── concrete fibers via specialize # user chooses a ↦ α
```

Automatic discovery of exceptional points (e.g. \(a=0\)) is **out of scope** here.

## Core test family

\[
[e_1, e_2] = a\, e_2
\]

| View | Center | Derived | Solvable / nilpotent |
|------|--------|---------|----------------------|
| Generic over \(\mathbb{Q}(a)\) | dim 0 | dim 1 | solvable, not nilpotent |
| Fiber \(a = 0\) | dim 2 | dim 0 | abelian (nilpotent) |

Unit tests must show `generic report ≠ specialize(L, a=>0)`.

## API

```julia
R, (a,) = polynomial_ring(QQ, [:a])
L_R = LieAlgebra(R, 2, Dict((1, 2) => [0, a]))   # over QQ[a]
L_K = generic_algebra(L_R)                         # coerce to QQ(a)
r_gen = analyze_generic(L_R)                       # = analyze(L_K)
L0 = specialize(L_R, Dict(a => 0))                 # fiber over QQ
r0 = analyze(L0)
```

Specialization **fails loudly** on poles (denominator zero). Jacobi of the
fiber may be re-checked; it is not assumed automatically from the family.
