# v0.1 Contract — Input / Skeleton / Output

## One-sentence goal

Given a **finite-dimensional Lie algebra by structure constants** over an
AbstractAlgebra/Nemo field (tests on \(\mathbb{Q}\)), **verify** it is a Lie
algebra and **compute classical invariants with certificates**.

---

## User input

Minimal constructor:

```julia
using ParametricLie
import Nemo

F = Nemo.QQ
# c[i,j,k] = a_{ijk}  such that  [e_i, e_j] = ∑_k a_{ijk} e_k
c = zeros(Nemo.QQFieldElem, 3, 3, 3)   # Array{elem_type(F),3}
# … fill antisymmetry: c[j,i,:] = -c[i,j,:] …
L = LieAlgebra(F, c)                   # Jacobi check via check_jacobi(L) (v0.1)
```

| Input piece | Meaning |
|-------------|---------|
| `F::Field` | Coefficient field parent (`Nemo.QQ`, `GF(p)`, …); not necessarily ℝ |
| Dense `c` | Full `n×n×n` structure constants |
| DOF `brackets` | Only independent pairs `(i,j) => coords` (sparse-friendly) |
| Optional | Basis names |

```julia
# Dense
L = LieAlgebra(F, c)                      # c::Array{C,3}

# Degree-of-freedom / sparse pairs (recommended for hand entry)
L = LieAlgebra(F, 3, Dict((1, 2) => [0, 0, 1]))   # [e1,e2]=e3; rest zero

# Abelian
L = LieAlgebra(F, n)
```

Constructors are distinguished by **argument types** (multiple dispatch), not by a flag:
`Array{C,3}` → dense; `(n, brackets)` → DOF. Internally both become a dense tensor in v0.1.

**Not** v0.1 input: a LieGroups manifold/`G`, parameters \(a,b\) as indeterminates
(that is v0.2), cocycle data (v0.3).

---

## Skeleton (what the package is)

```
User
  │  F + structure constants (n×n×n)
  ▼
LieAlgebra{C}          # types.jl — owns F, struct_consts (dim = n)
  │
  ├─ lie_bracket       # bracket.jl — [x,y] from c
  ├─ check_jacobi      # certificate (residuals / failing triples)
  ├─ change_of_basis   # change_of_basis.jl
  ├─ ad / adjoint      # bracket.jl
  ├─ LieSubspace       # subspace.jl
  ├─ center            # center.jl
  ├─ series / solvable # series.jl
  ├─ killing / Cartan  # killing.jl
  ├─ derivations       # derivations.jl
  └─ analyze(L)        # analyze.jl — one structured report
```

| File | Responsibility |
|------|----------------|
| `types.jl` | `LieAlgebra`, `coefficient_ring` (`F`), `structure_constants` |
| `bracket.jl` | `lie_bracket`, `ad`, `check_jacobi` |
| `change_of_basis.jl` | basis change for `L` and elements |
| `subspace.jl` | `LieSubspace`, `commutator_span` |
| `center.jl` | `center` |
| `series.jl` | derived / lower central, solvable / nilpotent |
| `killing.jl` | Killing form, Cartan criteria |
| `derivations.jl` | `Der` (placeholder) |
| `analyze.jl` | assemble report |
| *(later)* `radical.jl`, `quotient.jl`, `levi.jl` | solvable radical, semisimple quotient, Levi |
| `fixtures/` | known algebras + `expected.toml` |
| `test/` | unit / identities / examples / basis-change |

Exact linear algebra: **AbstractAlgebra/Nemo matrices**, not `Float64`.

---

## Expected output

### 1. Operations (interactive)

```julia
x, y = …                    # coordinate vectors in F^n
z = lie_bracket(L, x, y)    # vector in F^n

jac = check_jacobi(L)       # ok::Bool + witness (e.g. failing (i,j,k) or residual)
Z = center(L)               # subspace / basis matrix over F
D = derived_series(L)       # list of subspaces
killing_form(L)             # n×n matrix over F
derivations(L)              # basis of Der as matrices (or stacked)
L2 = change_of_basis(L, P)
```

### 2. `analyze(L)` report (primary deliverable UX)

Something like:

```text
LieAlgebra dim=3 over QQ

Jacobi: OK

center:           dim 1   basis = [e3]
derived_series:   3 → 1 → 0
lower_central:    3 → 1 → 0
solvable:         true
nilpotent:        true
Killing:          rank 0
Der:              dim 6   (basis available)
```

Every “dim” should be backed by an explicit basis / matrix the user can inspect
(`certificate`, not only `Int`).

### 3. Test / fixture output

For `fixtures/heisenberg/expected.toml`: computed invariants **match** expected
center dim, nilpotency, Killing rank, etc., and survive random change of basis
over \(\mathbb{Q}\).

---

## Success criterion for “v0.1 done”

1. User can define \(L\) from \(F\) + \(c\).  
2. `check_jacobi` + `analyze` work on abelian, Heisenberg, \(\mathfrak{sl}_2\).  
3. Results are exact over `Nemo.QQ` and basis-change invariant.  
4. No LieGroups dependency; no parameters; no cohomology.
