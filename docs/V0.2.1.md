# v0.2.1 — Parametric coefficient domains (free parameters)

## Goal

Represent Lie brackets over polynomial rings and rational-function fields, and
decide algebraic identities **exactly** over the chosen coefficient domain.

## In scope

- \(R = k[a_1,\ldots,a_m]\) with \(k\) a supported exact field (tests on \(\mathbb{Q}\))
- \(K = \mathrm{Frac}(R)\)
- Structure constants in \(R\) or \(K\)
- Exact bracket arithmetic
- Exact Jacobi identity testing
- Polynomial / rational **residual certificates**
- Canonical denominator tracking for rational-function families
- Explicit parameter metadata and domain-of-definition metadata

## Semantics

- Parameters are **algebraically independent** (free indeterminates).
- Equality in \(R\): \(f = 0\) means equality as a polynomial (all coefficients zero).
- Equality in \(K\): \(p/q = 0\) means \(p = 0\), with domain condition \(q \neq 0\).

## Out of scope

- Solving polynomial equations / enumerating parameter roots
- Constrained parameter varieties \(R/I\)
- Gröbner-based ideal membership
- Exceptional-locus decomposition
- Stratification
- Automatic case splitting (\(a=0\) vs \(a\neq 0\))

## Certificate examples

| Jacobi sum | Certificate |
|------------|-------------|
| \(J = 0\) | **identity** (`ok = true`) |
| \(J = a(b-1)\) | **nonidentity** with explicit residual \(a(b-1)\) (no solving) |
| \(J = (a-b^2)/(a+1)\) | numerator residual \(a-b^2\) plus domain \(a+1 \neq 0\) |

## API sketch

```julia
R, (a, b) = polynomial_ring(QQ, [:a, :b])
L = LieAlgebra(R, 3, Dict((1, 2) => [0, 0, a]))   # parametric Heisenberg
parameters(L)                 # [a, b] or [a]
jac = check_jacobi(L)        # JacobiCertificate(identity) if OK
jac.residuals                # explicit nonzero residuals if not
domain_denominators(L)       # for Frac families
```
